# 数据集说明

本文件为 skill 的填写规范。下文文档名称指目标项目中的对应产物，实际数据说明写入目标目录的 `2-data.md`，保留本规范。

记录项目使用的数据是什么、为何使用、如何形成，以及质量和适用范围。训练数据、验证数据、评测集和固定测试输入均纳入本文件；没有训练数据时注明原因，仍填写实际使用的测试数据。

## 填写约定

| 级别 | 填写方式 |
| --- | --- |
| 必填 | 每个数据集都要回答；尚未取得的信息写“待补充”，注明责任人和预计补齐时间 |
| 条件必填 | 满足表中的适用条件时必须填写；不适用时写“不适用：原因” |
| 选填 | 按项目需要填写，无需为凑齐文档补充 |

计划与实测分开记录。未知数字写 `null`，未检查或证据不可访问的结论写 `UNKNOWN`，不能用 `0` 或“无问题”代替。引用现有报告即可，无需复制报告全文。

| 信息 | 维护位置 |
| --- | --- |
| 数据集 ID、存储 URI、不可变版本 | 本文件各数据集的“版本与存储位置”项 |
| 数据含义、需求、构建过程、质量与限制 | 本文件 |
| 指标计算、评测方法和模型评测结果 | [3-eval.md](3-eval.md)；通过数据集 ID 与固定版本关联 |
| 单次实验实际使用的数据版本 | 对应 `experiments/EXP-xxx.md` |
| 影响项目的版本变化及处理进展 | [project.md](project.md) 中的实际节点 |

## 数据集：待填写

每个数据集复制本节，标题替换为数据集 ID。共享的格式、来源或处理流程可以引用同一段说明，但要标明各自差异。以下内容均应对应本节记录的固定版本；旧版本说明和报告通过 Git 历史及固定链接保留。

| 项目 | 必须说明什么 | 本数据集填写 |

| 获取与读取 | 访问方式、申请权限的入口或联系人、读取工具与方法；受限的使用范围注明来源约定 | 待填写 |

## 使用前检查

- [ ] 总览包含实际使用的全部数据集，ID 唯一，对应说明记录了固定版本和存储位置。
- [ ] 每个数据集的必填项已填写；缺失信息注明责任人和补齐时间。
- [ ] 条件必填项逐项判断适用性，适用项已补齐或明确待补充。
- [ ] 实际规模、分布和质量结论对应固定版本，附统计或检查证据。
- [ ] 计划要求与实测结果分开；未测或不可访问的内容保留 `null` / `UNKNOWN`。
- [ ] 实验、评测及进展中的数据引用与本次版本一致；版本变更的影响已记录。

本清单用于核对信息完整性，数据是否满足使用条件仍由接收标准和实际检查证据判断。
